# PhotoTrack

按地点整理照片的小工具：在空白地图上添加地点，照片按地点归档。  
<img src="camera.png" width="200"> 

## 想法
自从照片拍多，我发现整理照片非常麻烦，如果直接按文件夹分又不直观，那么一个直接的想法就是在地图上查找。事实上，我的手机相册已经有这个功能，但是它会将所有
同一地方拍的照片放在一起，这就导致在学校拍的风景照和学习工作的照片混在一起。而且照片会随着查找范围缩小而逐渐分散开，这本应该是件好事，但是不同缩放比例会使得拍摄位置较远的照片以不同程度分散开来。比如，从北京市的尺度来看，通州区和海淀区、朝阳区、西城区的照片会分散为两堆，每次要调整到适宜的尺度寻找很麻烦也不够优雅。  
因此，这个简洁高效的整理照片工具应运而生。


## 能做什么

**地图**
- 空白北京地图，可切换显示区界
- 输入地名自动定位
- 内置约 6600 个北京地点；找不到的可以在地图上点选后自己命名
- 标注自动避让、可拖动微调、滚轮缩放、比例尺

**照片**
- 每个地点一个照片库，支持拖拽批量导入
- 缩略图网格、大图浏览、左右翻页
- 改标题、写备注
- 多选后批量删除或移动到别的地点
- 每个地点独立回收站，可恢复
- 有照片的地点不能直接删，得先清空
- 照片的存储路径支持自定义

## 跑起来

```bash
node server.mjs --open
```

浏览器打开 `http://127.0.0.1:48765` 就能用。地图和地点库已随仓库提供，不用额外构建。

## 一些限制

- 暂时只做了北京，换城市要另配一套边界和地点库
